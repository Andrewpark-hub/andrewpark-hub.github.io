# jungunpark.com

박정언(Jungun Park)의 개인 사이트입니다. 프레임워크 없이 HTML, CSS, JS 파일 하나씩으로 만들었고 GitHub Pages로 올립니다. 주소는 https://jungunpark.com (가비아에서 산 도메인을 연결).

- `index.html` : 내용 전부 (한국어와 영어를 같이 적고 버튼으로 바꿔 보여 줌)
- `styles.css` : 디자인, 다크 모드, 모바일 화면
- `main.js` : 언어, 테마, 프로젝트 필터, 스크롤 애니메이션
- `assets/` : 사진, 파비콘

로컬에서 보기: `python3 -m http.server 8765` 후 http://localhost:8765
